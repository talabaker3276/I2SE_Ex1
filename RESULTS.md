## What existed before the correction

The previous repository text claimed four planes and approximately `0.055 s` / `72.59 FPS`. However the checked-in `planes.csv` then had only **three** triangle rows and the old script rejected 12-coordinate trapezoids. The timing methodology and machine were not independently documented. These historical figures therefore **must not be presented as verified results or evidence that the 500³ performance requirement was met**.

## Reproducible experiment to run

1. Obtain the original MRI file `MRHead_1.nrrd`, record file source and actual shape/dtype (and ideally SHA256).
2. Install requirements and run `python Ex0.py MRHead_1.nrrd planes.csv result.mp4`.
3. Confirm all four rows are accepted: three triangles, one trapezoid; decode `result.mp4` and check exactly four frames in order.
4. Record computer/CPU, Python version, NRRD dimensions/dtype, elapsed *projection* time, encoding time and resulting projection FPS.
5. For the >=30 FPS target, separately run a representative **500×500×500** volume with sufficiently many sample planes. Repeat trials and report median or distribution, not just four frames.
