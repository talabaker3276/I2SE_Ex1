# I2SE_Ex1 - 3D Volume Plane Projection

## Project Description
This project is part of the Introduction to Software Engineering course.
The goal of the project is to design and implement an efficient algorithm
for generating 2D plane projections from 3D volumetric data stored in NRRD format.

## Problem
Given a 3D raster data matrix and a plane defined by 3 or 4 points,
the program should compute a 2D image representing the projection of
that plane within the 3D volume.

## Project Scope
The project will:
- Read 3D volumetric data from an NRRD file.
- Read plane coordinates from a CSV file.
- Generate a 2D projection for each plane.
- Create an MP4 video containing the generated projections as frames.
- Test the correctness, stability, and performance of the implementation.
