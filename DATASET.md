# Dataset

## NRRD Data

The project uses 3D volumetric data stored in NRRD format.

The provided MRI file, `MRHead_1.nrrd`, will be used as the initial dataset for developing and testing the plane projection algorithm.

The file contains 3D MRI volumetric data that can be viewed using 3D Slicer.

Additional NRRD files may be added later to test the implementation with different 3D volumes.
