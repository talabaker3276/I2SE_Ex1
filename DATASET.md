# Dataset

## NRRD Data

The project uses 3D volumetric data stored in NRRD format.

The provided MRI file, `MRHead_1.nrrd`, was used as the dataset for developing and testing the plane projection algorithm.

The file contains 3D MRI volumetric data that can be viewed using 3D Slicer.

The loaded MRI volume has dimensions of 256 × 256 × 130.

The dataset was used to test both 3-point triangular planes and 4-point trapezoidal planes.

Additional NRRD files can also be used to test the implementation with different 3D volumes.
